# 📅 Расписание пар

## Описание

Страница расписания позволяет составлять и управлять недельным расписанием пар. Вы можете добавлять пары на каждый день недели, указывать время, предмет, преподавателя, аудиторию и тип недели.

## Возможности

### ✨ Основные функции

- **Добавление пар** - создавайте пары для любого дня недели
- **Редактирование** - изменяйте любую информацию о паре
- **Удаление** - удаляйте ненужные пары
- **Типы недель** - настройте повторение пар (каждую неделю, только чётную/нечётную)
- **Визуальное расписание** - удобное отображение в виде сетки по дням недели

### 📋 Информация о паре

Каждая пара может содержать:
- **День недели** - Понедельник-Суббота
- **Время начала и окончания** - точное время пары
- **Предмет** - название дисциплины
- **Преподаватель** - ФИО преподавателя (опционально)
- **Аудитория** - номер аудитории (опционально)
- **Тип недели** - повторение (каждую/чётную/нечётную)
- **Заметки** - дополнительная информация (опционально)

## Как использовать

### 1. Выполните SQL миграцию

Перед использованием расписания необходимо создать таблицу в базе данных:

1. Откройте **Supabase Dashboard** → **SQL Editor**
2. Скопируйте содержимое файла `supabase/migrations/004_add_schedule.sql`
3. Выполните SQL запрос

### 2. Добавьте пару

1. Перейдите на страницу **"Расписание"** в навигации
2. Нажмите кнопку **"Добавить пару"** или кнопку **+** на карточке дня
3. Заполните форму:
   - Выберите день недели
   - Укажите время начала и окончания
   - Введите название предмета
   - При необходимости добавьте преподавателя и аудиторию
   - Выберите тип повторения
   - Добавьте заметки (опционально)
4. Нажмите **"Создать"**

### 3. Редактируйте пару

1. Найдите нужную пару в расписании
2. Нажмите на иконку **редактирования** (карандаш)
3. Измените необходимую информацию
4. Нажмите **"Сохранить"**

### 4. Удалите пару

1. Найдите нужную пару в расписании
2. Нажмите на иконку **удаления** (корзина)
3. Подтвердите удаление

## Типы недель

### Каждую неделю
Пара повторяется каждую неделю без исключений.

### Только чётную неделю
Пара проводится только на чётных неделях (2-я, 4-я, 6-я и т.д. недели семестра).

### Только нечётную неделю
Пара проводится только на нечётных неделях (1-я, 3-я, 5-я и т.д. недели семестра).

## Структура данных

```typescript
interface ScheduleItem {
  id: string;
  user_id: string;
  day_of_week: 1 | 2 | 3 | 4 | 5 | 6; // 1=Пн, 6=Сб
  start_time: string; // HH:MM
  end_time: string; // HH:MM
  subject: string;
  teacher?: string | null;
  room?: string | null;
  notes?: string | null;
  week_type: 'every' | 'odd' | 'even';
  created_at: string;
  updated_at: string;
}
```

## База данных

Таблица `schedule` содержит следующие поля:

- `id` - UUID первичный ключ
- `user_id` - UUID пользователя (связь с profiles)
- `day_of_week` - день недели (1-6)
- `start_time` - время начала
- `end_time` - время окончания
- `subject` - название предмета
- `teacher` - преподаватель (опционально)
- `room` - аудитория (опционально)
- `notes` - заметки (опционально)
- `week_type` - тип недели (every/odd/even)
- `created_at` - дата создания
- `updated_at` - дата обновления

### Безопасность (RLS)

Включена Row Level Security. Каждый пользователь видит и может редактировать только своё расписание.

## Особенности реализации

### Оптимистичные обновления

Все операции (создание, редактирование, удаление) используют оптимистичные обновления - интерфейс обновляется мгновенно, а затем синхронизируется с базой данных.

### Автоматическая сортировка

Пары автоматически сортируются по дню недели и времени начала.

### Валидация

- Предмет обязателен
- Время начала и окончания обязательны
- Все остальные поля опциональны

### Realtime синхронизация

Расписание синхронизируется в реальном времени между устройствами через Supabase Realtime.
