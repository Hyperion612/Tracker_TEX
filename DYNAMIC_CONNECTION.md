# 🔌 Динамическое подключение к Supabase

## Что нового

Добавлена возможность подключаться к Supabase **без пересборки приложения**. Теперь вы можете:

1. Ввести URL и ключ прямо в браузере
2. Протестировать подключение
3. Сохранить настройки в localStorage
4. Всё приложение автоматически синхронизируется с вашей базой данных

## Как использовать

### Способ 1: Через страницу авторизации

1. Откройте приложение
2. На странице входа нажмите **"Для разработчиков"** (внизу формы)
3. Введите:
   - **Project URL**: `https://your-project.supabase.co`
   - **Anon Key**: ваш публичный ключ
4. Нажмите **"Тест подключения"** для проверки
5. Нажмите **"Сохранить и подключиться"**
6. Приложение автоматически перенаправит на страницу входа

### Способ 2: Через настройки

1. Войдите в приложение
2. Перейдите в **Настройки**
3. Найдите карточку **"Подключение к Supabase"**
4. Нажмите **"Настроить"**
5. Введите новые URL и ключ
6. Сохраните

### Способ 3: Автоматическое перенаправление

Если Supabase не настроен, приложение автоматически перенаправит вас на страницу подключения.

## Как это работает

### Хранение данных

- URL и ключ сохраняются в **localStorage** браузера
- Данные хранятся локально и не передаются на сторонние серверы
- Каждый пользователь может подключить свою базу данных

### Синхронизация

После подключения:
- ✅ Все данные (профили, посещаемость) синхронизируются с вашей Supabase базой
- ✅ Realtime обновления работают
- ✅ RLS политики применяются
- ✅ Данные изолированы между пользователями

### Пересоздание клиента

При изменении настроек:
1. Старый клиент Supabase удаляется
2. Создаётся новый клиент с новыми URL и ключом
3. Приложение автоматически перенаправляется
4. Все запросы идут на новую базу данных

## Получение URL и Key

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **Settings** → **API**
4. Скопируйте:
   - **Project URL** (например, `https://abcdefgh.supabase.co`)
   - **anon public key** (длинная строка, начинается с `eyJ...`)

## Безопасность

### ✅ Что безопасно

- **anon key** — публичный ключ, предназначен для клиентского использования
- **localStorage** — данные хранятся только в вашем браузере
- **RLS политики** — защищают данные в базе

### ⚠️ Что важно

- **НЕ публикуйте** свой `service_role key` — он даёт полный доступ к БД
- **НЕ коммитьте** `.env` файл с секретами в Git
- **Используйте RLS** — без него любой может получить доступ к данным

## Очистка настроек

Чтобы отключить базу данных:

1. Перейдите на страницу подключения (`/connect`)
2. Нажмите **"Очистить настройки подключения"**
3. Подтвердите действие
4. Приложение перенаправит на страницу подключения

## Технические детали

### Файлы

- `src/lib/supabase.ts` — клиент Supabase с динамической конфигурацией
- `src/pages/ConnectPage.tsx` — страница подключения
- `src/pages/LoginPage.tsx` — кнопка "Для разработчиков"
- `src/pages/SettingsPage.tsx` — карточка настройки подключения

### LocalStorage ключи

```javascript
tt_supabase_url      // Project URL
tt_supabase_anon_key // Anon Key
```

### API функции

```typescript
// Сохранить настройки
saveConnectionSettings(url: string, anonKey: string)

// Очистить настройки
clearConnectionSettings()

// Получить текущие настройки
getConnectionSettings(): { url: string; anonKey: string }

// Проверить подключение
isSupabaseConfigured(): boolean

// Тест подключения
testConnection(url: string, anonKey: string): Promise<{ success: boolean; error?: string }>
```

## Пример использования

```typescript
import { saveConnectionSettings, testConnection } from './lib/supabase';

// Тест подключения
const result = await testConnection(
  'https://your-project.supabase.co',
  'your-anon-key'
);

if (result.success) {
  // Сохранить настройки
  saveConnectionSettings(
    'https://your-project.supabase.co',
    'your-anon-key'
  );
  
  // Перезагрузить приложение
  window.location.reload();
}
```

## Troubleshooting

### "Подключение работает, но база данных не настроена"

Это означает, что подключение к Supabase работает, но таблицы не созданы.

**Решение**: Выполните SQL миграцию в Supabase SQL Editor.

### "Ошибка подключения"

Возможные причины:
- Неверный URL
- Неверный ключ
- Проект Supabase не существует
- Сетевые проблемы

**Решение**: Проверьте URL и ключ в Supabase Dashboard.

### Данные не сохраняются

Возможные причины:
- RLS политики блокируют запись
- Пользователь не авторизован
- Таблица не существует

**Решение**: Проверьте логи в Supabase Dashboard → Logs.

## Миграция с .env

Если вы использовали `.env` файл:

1. Скопируйте значения из `.env`
2. Вставьте в поля на странице подключения
3. Сохраните
4. Удалите `.env` файл (опционально)

Приложение будет использовать данные из localStorage вместо `.env`.
